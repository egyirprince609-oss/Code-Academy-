# VPN Force metadata artwork

`vpn-force-og-preview.jpg` is the 1200×630 metadata/social-preview image. To use it on the existing Code Academy website, copy it to the public website root and keep the `og:image` URL in the web metadata pointed at:

`https://egyirprince609-oss.github.io/Code-Academy-/vpn-force-og-preview.jpg`

The local Android UI includes Open Graph metadata for this path. Metadata tags are useful on a deployed public web page, not inside an installed APK's local WebView.
