📁 File Automation

EXPLANATION

This automation organizes files automatically into folders based on type. It removes manual sorting work completely. Python scans a folder using OS module. It checks each file extension like .jpg or .pdf. Then it decides destination folder. Shutil module moves files safely. This is used in data management systems and servers. It saves time and prevents messy storage. It runs continuously in background systems. 

import os, shutil

for file in os.listdir("downloads"):
    if file.endswith(".png"):
        shutil.move("downloads/"+file, "images/"+file)
Scan folder → detect file → check type → move file → complete

📧 Email Automation

This automation sends emails without manual typing. It uses SMTP protocol which handles email transfer. Python connects to Gmail server securely using TLS. It logs in using credentials. Then sends messages automatically. It is used in notifications and alert systems in companies. 

import smtplib

server = smtplib.SMTP("smtp.gmail.com",587)
server.starttls()
server.login("email@gmail.com","password")
server.sendmail("from","to","Hello")
Connect server → login → compose → send → confirm

⏰ Task Scheduler

This automation runs tasks repeatedly at intervals. It uses time module in Python. It is used in bots and background services. Python loops continuously and waits using sleep function. It is used for system monitoring and automated updates. It reduces manual execution of repeated tasks. 

import time

while True:
    print("Running task")
    time.sleep(5)
Start loop → execute task → wait → repeat
