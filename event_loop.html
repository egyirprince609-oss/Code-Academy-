🎯 What is the Event Loop?

Definition
The Event Loop is a loop that continuously checks if the Call Stack is empty. If empty, it takes the first task from Task Queue or Microtask Queue and pushes it to Call Stack for execution. This is how JavaScript handles async code without blocking the main thread, even though JS has only 1 thread.

⚡ Microtasks vs Macrotasks - The Key Rule

The Golden Rule
Golden Rule: After Call Stack empties, Event Loop runs ALL microtasks first, then runs ONE macrotask. Then checks microtasks again. Microtasks = Promises, queueMicrotask. Macrotasks = setTimeout, setInterval, setImmediate.
Priority Example - Predict Output
console.log('1. Start'); setTimeout(() => { console.log('4. setTimeout - Macrotask'); }, 0); Promise.resolve().then(() => { console.log('3. Promise - Microtask'); }); console.log('2. End'); // OUTPUT: 1, 2, 3, 4 // Why? Microtasks run before Macrotasks
Line 1: console.log('1. Start')

Synchronous code. Goes straight to Call Stack and executes immediately. Output: 1. Start

Line 3-5: setTimeout()

setTimeout is Web API. Browser handles timer. After 0ms, callback goes to Task Queue. This is Macrotask - low priority.

Line 7-9: Promise.resolve().then()

Promise callback goes to Microtask Queue. This is high priority. Even with 0ms timeout, Promise always runs before setTimeout.

Line 11: console.log('2. End')

Synchronous code executes immediately. Output: 2. End. Now Call Stack empty, Event Loop checks Microtask Queue first → runs Promise → Output: 3. Promise. Then runs Macrotask → Output: 4. setTimeout

🎓 Interview Question: Predict Output

Hard Question
console.log('A'); setTimeout(() => console.log('B'), 0); Promise.resolve().then(() => { console.log('C'); Promise.resolve().then(() => console.log('D')); }); console.log('E'); // OUTPUT: A, E, C, D, B // Try to figure out why D comes before B
Answer:
1. A and E print immediately - synchronous
2. setTimeout B goes to Task Queue
3. Promise C goes to Microtask Queue
4. Call Stack empty → Event Loop runs all microtasks → C prints
5. Inside C, new Promise D added to Microtask Queue → D prints immediately
6. Microtask Queue empty → Event Loop takes one macrotask → B prints

Key: Microtasks can add more microtasks, and Event Loop keeps running them until queue is empty before moving to macrotasks.
