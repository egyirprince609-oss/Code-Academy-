BEFORE YOU BEGIN

Welcome to Code Breaker

This is your orientation. Read the rules or press the AI Guide button to hear a personalized explanation. When you are ready, enter the arena and start your timer.

1. Inspect the code

Read the code carefully. Each level contains a programming mistake. Look for missing symbols, incorrect conditions, misplaced punctuation or faulty logic.

2. Choose the correct answer

Select the option that identifies the bug. If your answer is incorrect, review the feedback and try again. You do not lose XP for an incorrect answer.

3. Use hints wisely

Hints provide clues for the current level. Each hint you request costs 50 XP and 25 coins. Your balance must cover both costs before a hint is revealed.

4. Earn your badges

Successfully complete a level to earn its badge, 10 XP and 5 coins. Each level can award its completion reward only once.

5. Track your time

Your game timer starts when you enter the arena. Active time is saved periodically, including the daily total and the cumulative time recorded for this game.

6. Improve with every level

Progress through ten levels, from basic syntax errors to more demanding code analysis. Use the history page to review sessions, rewards, hints and completed levels.
