Code Editor · Complete guide
Build projects, understand the runtime, and keep your work safe.


 1. Create files and folders
Tap either + file button to open the filename dialog. Enter a name such as index.html, style.css, script.js, main.py or src/App.jsx. Select a starter template if you omit the extension. The extension determines syntax highlighting and the language logo. Use folder paths such as src/components/Card.jsx to organize a project.


 2. Run and preview
HTML / CSS / JavaScript: Run opens a sandboxed preview and sends console messages and browser errors to the Console tab. React JSX / TSX: Run uses React and Babel loaded from a CDN; it is a practice preview, not a full npm/Vite build. JSON: Run validates JSON and displays formatted data.


 3. Python compiler
Python runs through Pyodide in a JavaScript module worker, keeping most computation away from the user interface. The first run downloads the runtime, so an internet connection is needed. Imported packages are loaded when Pyodide supports them; native packages that require unavailable system binaries may not work. Output and Python errors appear in the Console. Use Stop to interrupt a long-running program.


 4. Language support
Editing and highlighting cover HTML, CSS, JavaScript, TypeScript, React JSX/TSX, Python, C, C++, Java, C#, PHP, Go, Rust, Ruby, Kotlin, Swift, Dart, SQL, JSON, Markdown, XML, YAML and Shell. C/C++/Java and server-side languages need a separately configured compiler or runtime service to execute; highlighting alone does not compile them.


 5. Large files and performance
The editor does not reject a file because it crosses a fixed line-count limit. For larger documents, it automatically turns off costly wrapping, suggestions and decorations to improve responsiveness. Very large source files can still use substantial phone memory, and millions of lines cannot be promised to run instantly. Execution time depends on the program and the device. The Console keeps recent output instead of creating unlimited DOM rows.
Cloud-save note: projects are currently stored as one Firestore document. Firestore has a strict per-document size limit, so an oversized project may stay editable locally but cannot be saved in that one document. Use Export project backup and keep a copy; large-project cloud storage needs a per-file storage design.


 6. Saving and shortcuts
Ctrl+S saves the project, Ctrl+Enter runs the active code, and Ctrl+B toggles the file explorer. Automatic saving is debounced while typing. The cloud indicator shows whether changes are pending, saved or blocked. Use Export Backup for an offline copy and Import Backup to restore a Code Academy project file.
