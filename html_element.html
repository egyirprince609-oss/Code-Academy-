📚 HTML Elements

40 Essential HTML Elements

Learn the most used HTML tags with live examples. Every website uses these!

1. HTML Root <html>

Root of every webpage
<html lang="en"> ... </html>

2. Document Type <!DOCTYPE>

Tells browser this is HTML5
<!DOCTYPE html>

3. Head <head>

Contains meta info, title, links
<head><title>Page</title></head>

4. Title <title>

Shows in browser tab: Code Academy
<title>My Website</title>

5. Body <body>

Everything visible goes here
<body>Content here</body>

6. Meta <meta>

SEO + viewport settings
<meta charset="UTF-8">

7. Link <link>

Connect CSS files
<link rel="stylesheet" href="style.css">

8. Script <script>

Add JavaScript
<script>alert('Hi');</script>

9. Style <style>

Write CSS inside HTML
<style>body{color:red}</style>

10. Div <div>

Container box
<div>Content block</div>

11. Heading 1 <h1>

Main Title

<h1>Main Title</h1>

12. Heading 2-6 <h2>-<h6>

H2

H3

H4

<h2>Subtitle</h2>

13. Paragraph <p>

This is a paragraph of text.

<p>Your text here</p>

14. Line Break <br>

Line 1
Line 2
Text<br>New line

15. Horizontal Rule <hr>

Above
Below
<hr>

16. Bold <strong>

Important text
<strong>Bold text</strong>

17. Italic <em>

Emphasized text
<em>Italic text</em>

18. Small <small>

Small text
<small>Copyright 2026</small>

19. Mark <mark>

Highlight yellow text
<mark>Highlighted</mark>

20. Span <span>

Text with colored word
<span>Inline text</span>

21. Anchor Link <a>

Go to Google
<a href="url">Click me</a>

22. Image <img>

<img src="photo.jpg" alt="description">

23. Unordered List <ul>

  • Item 1
  • Item 2
<ul><li>Item</li></ul>

24. Ordered List <ol>

  1. Step 1
  2. Step 2
<ol><li>Step</li></ol>

25. List Item <li>

Used inside ul/ol
<li>List item</li>

26. Table <table>

NameAge
John25
<table><tr><td>Data</td></tr></table>

27. Table Row <tr>

Row in table
<tr>...</tr>

28. Table Data <td>

Cell in table
<td>Content</td>

29. Table Head <th>

Header cell
<th>Header</th>

30. Button <button>

<button>Submit</button>

31. Form <form>

Container for inputs
<form>...</form>

32. Input <input>

<input type="text">

33. Label <label>

<label>Email:</label>

34. Textarea <textarea>

<textarea></textarea>

35. Select <select>

<select><option>...</option></select>

36. Header <header>

Top section
<header>Navigation</header>

37. Nav <nav>

Menu links
<nav>Menu</nav>

38. Section <section>

Content section
<section>About us</section>

39. Article <article>

Blog post
<article>Post content</article>

40. Footer <footer>

Bottom section
<footer>Copyright</footer>
