Documentation and data basics

Here is a high-level guide to the main areas and how this version handles information. Review the official policies for the complete rules.

Account and authentication

Sign-up and sign-in are handled by the existing Firebase authentication setup. Protected learning areas may require an account. Email verification may be required for password-based accounts.

Account-linked progress

When online, the account system and game bridge can store profile progress, XP, coins, game history and in-app notifications under the signed-in user's Firebase records.

Device-only preferences

The preferred learning language and the added practice-bank position/answers are stored in local storage on the current browser/device, not uploaded to Firebase by these new practice controls. Clearing browser data may remove them.

Translation and AI voice

Speech uses the browser/device speech synthesis engine and a matching language voice where available. Practice text may be sent to a third-party translation service when a different language is selected. Availability and quality vary; code snippets are left unchanged.

Offline support and notifications

The service worker caches key pages and question banks after successful loading. Push notifications require a compatible browser, permission, and a configured push sender/server. A web page cannot guarantee arbitrary timers keep running after the app is fully closed.

Safe and responsible use

Do not enter passwords, payment secrets or highly sensitive information into code examples, practice answers or public support channels. Always use trusted official sources for security-related claims.

*Course availability is determined by the current lesson dashboard. Features may depend on network connection, device, browser support and account permissions.

Frequently asked questions

Helpful to know

Can I read this page without an account?

Yes. This public landing page and its documentation do not require sign-up.

Will the games work offline?

Files already cached by the browser may work offline. First-time loading, authentication, cloud rewards, translation and remote services need internet access.

Will my selected language change programming syntax?

No. The practice translation feature targets explanatory text and answer choices. Code samples and language keywords are intentionally left unchanged.

Does a PWA support every background task like a native app?

No. PWA capabilities depend on browser and operating system support. Push messages need a server or push provider, and a standard service worker cannot run an arbitrary timer continuously after termination.

Where can I read the policies?

See the Privacy Policy, Terms, About Code Academy or Contact.
