# Browser preview index

All image files in this folder are **static design mockups**, not screenshots of a running APK or emulator. They are included to review layout and visual hierarchy before on-device QA.

- `browser-home-preview.png` — **Home / new tab**: Search input, quick access, recent sites and privacy note.
- `browser-live-page-preview.png` — **Live webpage controls**: A design example of a real top-level WebView page and browser controls.
- `browser-tabs-preview.png` — **Tab switcher**: Active tab, URL/title, close and new-tab controls.
- `browser-bookmarks-history-preview.png` — **Bookmarks and history**: Saved sites, visit times and history sync privacy.
- `browser-metadata-preview.png` — **Site information and metadata**: Title/description/preview, connection origin and untrusted metadata note.
- `browser-settings-preview.png` — **Settings and privacy**: Search provider, JS, text size, history and Safe Browsing status.
- `browser-error-preview.png` — **TLS / connection error**: Native warning state and retry/exit path without certificate bypass.
