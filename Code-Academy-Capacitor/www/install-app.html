Install the Android app to use Code Academy in an app-style experience. The APK is published as a GitHub Release; Firebase Hosting contains this guide and website only.

Download latest Android APK View all releases

If the download is not ready yet, open the releases page and check the newest build.

How to install on Android

  1. Tap Download latest Android APK and wait for the file download to finish.
  2. Open the downloaded Code-Academy.apk. If Android asks, allow installation from this browser or file manager in Settings.
  3. Return to the installer and tap Install. When it finishes, tap Open.
  4. For updates, download a newer APK signed with the same Code Academy release key, then install it over the existing app.

Camera, microphone and location

Android will ask for permissions when a relevant feature needs them. Allow camera access for camera features, microphone access for recording or voice features, and location access for location-based features. Choose precise location only when that feature needs it; you control these settings in Android Settings at any time.

Allow notifications if you want reminders. Android may restrict background work to save battery; this does not mean the app can continuously record audio or track location in the background.

Safety note

Install APK files only when they come from the official Code Academy GitHub repository. Never share your Firebase password, GitHub token, keystore, or signing-key passwords.
