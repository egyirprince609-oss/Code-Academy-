About the app

Meet Code Academy: learn, build, grow.

Code Academy is an independently developed learning workspace built around a simple idea: technology becomes easier to understand when you can read a concept, try it, make mistakes, and practise again. It brings lessons and practical tools together while remaining a work in progress.

What we are building

A place to connect concepts with practice.

The goal is not to promise that every tool replaces a professional development environment. It is to give learners a friendly place to get started, experiment, revisit key ideas, and build confidence through practice.

  • Start from foundational programming lessons and work toward more advanced topics.
  • Read sample code and test selected languages in the editor routes where runtimes are configured.
  • Practise recall and problem-solving through quizzes, games, and challenges.
  • Keep track of learning activity where saved-progress features are enabled.
  • Explore additional tools without treating every feature as a production-grade service.

Frequently asked questions

Quick answers about the app.

These answers describe the platform at a general level. The in-page notice for a specific feature takes priority for that feature's exact requirements.

Is Code Academy only a coding lesson website?

No. It includes lessons and reference pages as well as editor routes, project tools, quizzes, games, study planning, selected AI helpers, a textbook library, certificates, a community route, Live Map, and browser utilities. Availability can vary.

Do these public pages require authentication?

No. The landing page, About page, documentation, Privacy Policy, and Terms of Use are public. Some app features sign you in to associate saved learning progress or other account-linked data with your profile.

Can I run code for any language in the editor?

Not every language uses the same runtime. Some examples run or preview in your browser; some selected compiled-language runs send code to an external compiler service. Read the runtime prompt in the editor before submitting code.

Can I use the security lessons on public websites?

Only where you have explicit permission for the target and the activity. Learning about security is not permission to probe or access someone else's system. Use training labs or systems you own and follow the agreed scope.

How do certificate verification links work?

Open Verify Certificate for the standard certificate registry, the Cybersecurity Certificate Verifier for security-track credentials, or the Textbook Certificate Verifier for a textbook credential. Use the verifier that matches the credential and enter its ID or open its verification link.

Does Live Map show a real-time camera view of my neighbourhood?

No. It displays map imagery and geographic information from map providers, which may be incomplete or dated. It is not a live camera feed and does not guarantee survey-grade location accuracy.

How can I report a problem or suggest an improvement?

Use the Support Center. Describe the page and steps that led to the problem. Include only information needed to troubleshoot and remove private account details or credentials from screenshots.

Where can I learn about data and permissions?

Read the Privacy Policy for account data, browser storage, GPS, notifications, file selection, compilers, AI tools, map services, and other third parties. The Terms of Use describes how the service is expected to be used.
