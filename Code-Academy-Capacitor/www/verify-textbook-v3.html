PUBLISHER REGISTRY CHECK

Check the official record.

Scan the QR code or barcode, or type the printed details below. Results come from the Code Academy Firebase textbook registry. A QR image alone is not proof; this page checks the record stored by the publisher.

Privacy: verification uses the book’s public ID and its publisher verification code. It does not need a learner account.

Scan or enter book details

Camera scanning requires HTTPS (GitHub Pages provides HTTPS) and camera permission. A printed barcode contains the book ID; the QR includes both the ID and verification code.

How the result works

Valid textbook record

The book ID is present and marked valid in Firebase. If a verification code was also supplied, the code must match.

Unregistered ID

No matching publisher record was found. Treat the copy as unverified and contact Code Academy before relying on it.

Code mismatch or revoked book

The ID may exist, but the supplied code did not match or the registry marks the book as revoked. Contact the publisher.

A copied QR or barcode can be reproduced. This registry checks whether an identifier has been issued; it does not establish the physical uniqueness of a printed copy.
