Modern CSS Layouts

Master Flexbox and Grid - The 2 layout systems every developer must know

1. Flexbox - 1 Dimensional Layout

Flexbox is perfect for arranging items in a row OR column. Use it for navbars, button groups, and centering content.

Box 1
Box 2
Box 3
.container {
  display: flex;
  gap: 15px;
  justify-content: space-between;
}

.item {
  flex: 1; /* Equal width */
  padding: 40px;
}
💡 Pro Tip: Use justify-content: center to center items horizontally, align-items: center to center vertically.

2. CSS Grid - 2 Dimensional Layout

Grid is for complex layouts - rows AND columns at the same time. Perfect for dashboards, galleries, and page layouts.

.grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(150px, 1fr));
  gap: 15px;
}

.item {
  padding: 40px;
}
💡 Pro Tip: auto-fit + minmax() makes grid automatically responsive. No media queries needed!

3. Flexbox vs Grid - When to Use What?

Use FLEXBOX when:
• 1 row OR 1 column
• Centering content
• Navbars, buttons
• Distributing space

Use GRID when:
• Rows AND columns
• Complex page layouts
• Galleries, dashboards
• Overlapping elements

PRO SECRET: Use them together!
Grid for page layout, Flexbox for components.
