🚀 Lazy Loading Speed +70%
What is it?
Lazy Loading loads components only when the user needs them. Uses React.lazy() and Suspense to split code and reduce initial bundle size by 70%. Essential for large applications.
Initial Load 45 KB
After Lazy Load 15 KB

Complete React Code
import React, { lazy, Suspense, useState } from 'react'; // Lazy load heavy component const HeavyChart = lazy(() => import('./HeavyChart')); function Dashboard() { const [showChart, setShowChart] = useState(false); return ( <div> <h1>Dashboard</h1> <button onClick={() => setShowChart(true)}> Load Chart </button> {showChart && ( <Suspense fallback={<div>Loading chart...</div>}> <HeavyChart /> </Suspense> )} </div> ); } export default Dashboard;
💾 React.memo Renders -80%
What is it?
React.memo is a higher order component that prevents unnecessary re-renders. If props haven't changed, React skips rendering. Reduces renders by 80% in large lists.
Child Renders Without Memo 0
Child Renders With Memo 0
Click button - watch renders difference
Complete React Code
import React, { useState, memo } from 'react'; // Memoized child component const ExpensiveChild = memo(({ value }) => { console.log('Child rendered:', value); return <div>Value: {value}</div> }); function Parent() { const [count, setCount] = useState(0); const [other, setOther] = useState(0); return ( <div> <button onClick={() => setCount(count + 1)}> Count: {count} </button> <button onClick={() => setOther(other + 1)}> Other: {other} </button> <!-- Child only re-renders when count changes --> <ExpensiveChild value={count} /> </div> ); } export default Parent;
🔄 useCallback Props Stable
What is it?
useCallback memoizes functions so they don't get recreated on every render. Prevents child components from re-rendering when functions are passed as props. Critical for performance.
Function Reference Stable ✓
Child Re-renders 0
useCallback keeps function reference same
Complete React Code
import React, { useState, useCallback, memo } from 'react'; const ChildButton = memo(({ onClick }) => { console.log('Child rendered'); return <button onClick={onClick}>Click Me</button> }); function Parent() { const [count, setCount] = useState(0); // Without useCallback - new function every render // const handleClick = () => console.log('clicked'); // With useCallback - same function reference const handleClick = useCallback(() => { console.log('clicked'); }, []); return ( <div> <button onClick={() => setCount(count + 1)}> Count: {count} </button> <!-- Child won't re-render when count changes --> <ChildButton onClick={handleClick} /> </div> ); } export default Parent;
