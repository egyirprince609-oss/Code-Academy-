🧩 1. What is a Component?

Detailed Explanation +
A React component is a reusable, self-contained building block that defines a part of the user interface. Think of it like LEGO pieces - you combine small components to build complex applications.

Key Benefits:
• Reusability: Write once, use everywhere
• Maintainability: Isolated logic, easier to debug
• Scalability: Large apps broken into manageable pieces
• Team Collaboration: Different devs work on different components

Without components, you'd write repetitive HTML/CSS/JS. Components eliminate duplication and make your codebase clean and organized.

🚀 2. Why Components Matter

Deep Dive +
Components are the foundation of modern web development. They solve real problems developers face daily.

Why They Matter:
• DRY Principle: Don't Repeat Yourself - write code once
• Single Responsibility: Each component does one thing well
• Testing: Small components are easier to unit test
• Performance: React optimizes re-rendering at component level
• Reusability: Build a button once, use it 100 times

Companies like Facebook, Netflix, Airbnb build entire platforms using component architecture. It's industry standard for a reason.

💻 3. Sample React Component

import React from "react"; function Button({ children, onClick, variant = "primary" }) { return ( <button className=`btn btn-`{variant} onClick={onClick}> {children} </button> ); } export default Button;
Line 1: Imports React library. Required for JSX syntax to work.

Line 3: Defines functional component named Button. Uses destructuring to accept props: children, onClick, variant.

Line 4: Returns JSX - HTML-like syntax that React converts to real DOM elements.

Line 5: Creates button element with dynamic className using template literals. variant prop changes button style.

Line 6: Renders children prop - whatever content you pass between Button tags.

Line 9: Exports component so other files can import and reuse it.

Props Explained: children = content inside tags, onClick = function to run when clicked, variant = style variant like primary/secondary.
