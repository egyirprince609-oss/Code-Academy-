Python Studio quick guide

Write Python in the editor, then select Run Python. Your output is shown in the Console. Save stores files in your existing Code Academy Firestore project format, so the workspace is visible in the saved-projects page.

Libraries: imports for packages bundled with Pyodide are fetched as needed. Use the package installer for other compatible packages. Packages with unavailable native binaries, desktop UI dependencies, or OS-specific components may not install or run.

Privacy: code executes in a browser worker and is not sent to a third-party code execution server. Package downloads still require the configured CDN or package registry.
