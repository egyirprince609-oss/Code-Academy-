1. Getting started

The landing page explains the main areas of Code Academy. You can open the public landing page, About page, documentation, Privacy Policy, and Terms of Use without signing in.

  1. Choose Courses to find a learning path.
  2. Open a lesson or resource that matches your level.
  3. Use the examples, quiz, or editor to practise the concept.
  4. Create an account through Get started when you need account-linked learning progress, profile features, or cloud saving. Existing users can use Sign in.

Some app tools may redirect to the sign-in page or ask you to authenticate before an account-based action. A public documentation page does not itself authenticate you.

Install or add Code Academy to your home screen

On a supported browser, open the browser menu and look for Install app or Add to Home screen. If the browser presents an in-app install option, follow its prompt. The exact wording varies across Android, desktop, and other browsers. If no install option appears, you can still bookmark the website and open it normally. Installation does not remove the need for internet access for features that use accounts or external services.

2. Courses, lessons, and textbooks

Code Academy includes lesson and reference material across web foundations and numerous programming languages, plus dedicated cybersecurity and ethical-hacking topics. Use the course directory to browse what is available in the current project.

Lessons can include explanations, code examples, application questions, quizzes, diagrams, reference links, and progress records. The content and controls vary by course. Some lesson pages provide language selection, narration, or a lesson-history view.

The textbook library provides a separate route for supported textbook content. Textbook sign-in or certificate checks may use their own pages; follow the notice shown on the page you are using.

A learning path, language reference, or syntax-highlighted editor does not automatically mean a complete compiler is available for that language.

3. Editors and running code

Start from the Editor Dashboard or Code Editor. Available routes include general editing and language-specific workspaces. The editor may support project files, folders, syntax-aware editing, browser preview, or a language runtime depending on the selected language.

Editor behaviourWhat to expect
HTML/CSS/JavaScript and selected React previewsSupported code can be previewed in a browser workspace. Browser sandbox limitations and external website security policies still apply.
PythonSelected Python routes use a browser-based runtime. First load may download runtime resources and require available memory and internet access.
TypeScript and SQL toolsWhere configured, TypeScript can be transpiled in the browser and SQL can run in a temporary in-memory teaching database. That SQL database is not a production data service.
Selected compiled languagesSome compile/run actions send source code and necessary input to an external compiler provider. A confirmation may appear before the code is sent.

Safe editor habits

  • Read the run/compile notice before submitting code.
  • Remove passwords, private keys, API keys, personal data, and confidential business logic from examples.
  • Check the output and treat compiler/network errors as errors—not successful execution.
  • Keep a separate backup of important files.

4. Projects, files, and saved work

Open the Project workspace or explore ready-made project ideas. Depending on the page, you may be able to create files, organise folders, import selected files, preview a project, or save work to an account.

Project saving and local recovery are not a substitute for independent backups. If you import a folder or select files, only choose the material you want that workspace to access. Do not include credentials or confidential content. When a feature stores files in the cloud, those files are processed by the service provider configured for that feature.

5. Quizzes, challenges, and games

Use the Games Arena, quiz route, and challenge pages to practise concepts through short activities. Different activities have their own rules, scoring, hearts, timers, or progress displays.

XP, coins, streaks, badges, and scores are learning indicators. Unless a separate written offer states otherwise, they have no cash value and are not redeemable for money. A saved score or completion status can depend on connectivity, sign-in state, and the feature's configured storage.

6. AI and language tools

Selected AI-assisted pages may help explain a concept or provide a starting point. Open AI Mentor where available. Models may generate incorrect, incomplete, unsafe, or outdated answers. Test code and independently check important advice.

When you submit a prompt, question, or code sample to an AI feature, that input may be sent to the provider configured for that page. Different pages may use different providers; internet access may be required. Do not submit secrets, private records, or confidential source code.

Some lessons or games provide translation, language selection, or speech narration. Available language options and quality vary; automatic translation can change the meaning of technical details. Compare the original wording when a result matters.

7. Study planner and notifications

Use the Study Planner to organise study targets and review plan information. If the page offers notifications, it may ask your browser for permission. You can say no or revoke permission in browser settings.

Notification behaviour depends on browser support, device settings, connectivity, and the implementation used by that feature. A page running only in the browser cannot guarantee that all reminders will arrive while the browser or app is completely closed.

8. Certificates and verification

Where the course and account qualify, the certificate flow may offer eligibility checks, issue a record, show a certificate, or provide a public verification URL. Course requirements differ; use the information shown by that certificate centre.

Verify a standard certificate

  1. Open Verify Certificate.
  2. Enter the credential ID exactly as shown or open the verification link supplied with the certificate.
  3. Check the returned record and its status. If no match is found, check for a typing error and confirm that you opened the correct verifier for the certificate type.

Verify a cybersecurity certificate

For security-track certificates, use the Cybersecurity Certificate Verifier.

Verify a textbook credential

For a textbook-related credential, open the Textbook Certificate Verifier and follow the instructions on that page. Standard, security, and textbook records may use different registries, so choose the matching verification route.

A certificate is a platform learning record, not automatically an accredited academic qualification or professional licence. A screenshot alone is not a registry verification.

9. Cybersecurity and ethical-hacking learning

Dedicated security tracks cover defensive security ideas and authorised assessment. Start with the Cybersecurity Dashboard or Ethical Hacking Dashboard.

Only practise on systems you own or systems for which you have explicit permission covering the target and testing method. Use training labs, follow the agreed scope, protect evidence, and stop when testing risks unintended harm. Lessons do not give you permission to assess a public website or another person's device.

10. Live Map and GPS

Open Live Map to explore supported map features. The page can request geolocation after you start a location function and grant permission. If you enable live updates, the page may read device location while the feature is running. Location sharing is a separate action.

Map providers may receive requests for map tiles, place searches, reverse-geocoding, or coordinates. Map imagery can be incomplete or dated, and device location accuracy varies. The map is not a real-time camera feed or survey-grade system.

11. Browser workspace and safety utilities

Open the Browser Workspace or Safe Browser to use supported web-navigation and safety utilities. External websites may open in a separate device-browser tab and have their own privacy practices.

Selected IP, DNS, URL, domain, or safety checks may send the query to a third-party service. These features can provide useful signals but cannot guarantee that a site is safe or malicious, and they cannot inspect or control every external browser page.

12. Language, accessibility, and mobile use

The public pages use responsive layouts, keyboard focus styles, semantic headings, and controls intended to fit small and large screens. Some app pages additionally offer language selection, speech narration, translation, or notification features.

Language options and screen-reader behaviour may vary by page. Browser speech voices depend on voices installed or provided by the device. If a page looks crowded on mobile, try rotating the device, reducing browser zoom, or opening the section navigation rather than using horizontal scrolling. Report a layout bug via Support.

13. Privacy and security basics

Read the full Privacy Policy to understand account details, learning records, browser storage, file uploads, notifications, GPS, AI prompts, external compilers, map providers, and security lookups. The Terms of Use describes expected behaviour.

  • Use unique account credentials and never share verification codes.
  • Keep passwords, private keys, API tokens, and private personal information out of code examples, screenshots, prompts, and support requests.
  • Review compiler, AI, map, and security-tool disclosures before submitting data.
  • Grant only the browser permissions you need and revoke them when finished.
  • Back up important projects outside the app.

14. Troubleshooting

A page is blank or will not load

  • Check the internet connection and reload the page.
  • Try a modern browser and make sure JavaScript is enabled.
  • Check whether the feature depends on an external provider or an account session.

An editor run fails

  • Read the message shown by the editor. Check that the language/runtime is supported on that route.
  • Check connectivity for external compiler providers and allow the first runtime assets to finish loading.
  • Remove secrets and try a short non-sensitive example to isolate the problem.

A project or progress record is missing

  • Confirm that you are signed in to the expected account.
  • Check whether the feature stores data locally or remotely; clearing browser storage may delete local copies.
  • Check whether a save action displayed confirmation before leaving the page.

A certificate cannot be verified

  • Copy the credential ID carefully and remove accidental spaces.
  • Use the standard or cybersecurity verifier that matches the certificate type.
  • If the identifier still returns no record, contact support with the credential ID and avoid sending unrelated personal documents.

A notification or location feature does not work

  • Check browser permission for notifications or location and the device's site settings.
  • Confirm that the relevant feature is currently active and that the browser supports it.
  • Remember that location-dependent tools cannot work if permission is denied.

Frequently asked questions

Can I read documentation without an account?

Yes. This documentation and the other public information pages do not require sign-in. You may need an account for progress, cloud saving, or other account-linked tools.

Does seeing a language listed mean its code will run here?

No. A language can have lesson or reference material without an available browser runtime. The editor's selected run method and on-screen notice determine how execution is performed.

What information does certificate verification show?

The verifier checks the relevant configured credential record. The fields shown depend on the certificate type and registry. Use the correct verifier and do not rely on a screenshot alone.

Does a Live Map permission mean that Code Academy always tracks me?

No. Browser geolocation is requested by a location feature after you activate it and grant permission. Use the page's stop control or leave the page to stop its active updates; share a location separately only when you choose to.

Are AI answers and safety checks guaranteed correct?

No. AI output may be incorrect and URL/domain safety signals are limited. Verify important results independently and do not deploy generated code or rely on a safety signal without review.
