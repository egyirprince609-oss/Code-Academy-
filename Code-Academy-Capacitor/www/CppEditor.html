C++ Studio quick guide

Create .cpp, .h and .hpp files, organize them into folders, and save your complete project. The file format matches the rest of Code Academy: a files map plus a folders map in users/{uid}/projects/{projectId}.

Run and compile: The editor dynamically loads currently available GCC and Clang compiler options from Compiler Explorer. Choose C++11, C++14, C++17, C++20 or C++23. The service compiles and can execute supported programs in an isolated environment; internet access is required for these actions.

Libraries: Headers such as iostream, vector, string and algorithm belong to the compiler's standard library and need no separate download. Optional third-party libraries are discovered through Compiler Explorer's library endpoint.

Privacy: Unlike the Python editor's local Pyodide runtime, this C++ compiler service receives your source code and project source files for compilation. Do not submit secrets or personal data. Saving your workspace still uses your existing Firebase account and Firestore project format.
