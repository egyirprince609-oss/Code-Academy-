Core Concept

Variables & Data Types

Variables are containers used to store data in Python. Every value in Python has a type such as integer, string, float, or boolean. Understanding data types helps you control how your program behaves and processes information.
  • int → whole numbers like 10, 50
  • float → decimal numbers like 3.5
  • str → text like "Hello"
  • bool → True or False conditions
name = "John"
age = 20
height = 5.9
is_student = True

print(name)
print(age)
Control Flow

Loops

Loops allow you to repeat a block of code multiple times without rewriting it. Python provides for-loops for known repetitions and while-loops for condition-based repetition.
  • for loop → used when number of repetitions is known
  • while loop → runs until condition becomes false
  • helps reduce repeated code and improves efficiency
for i in range(5):
    print("Hello")

x = 0
while x < 5:
    print(x)
    x += 1
Reusable Code

Functions

Functions are reusable blocks of code designed to perform a specific task. They help you avoid repetition, organize your program, and make your code easier to maintain and debug.
  • Defined using the def keyword
  • Can accept parameters (inputs)
  • Can return results for reuse
def greet(name):
    print("Hello", name)

greet("Alice")
Data Storage

Lists

Lists are used to store multiple values in a single variable. They are ordered, changeable, and allow duplicate values. Lists are one of the most powerful data structures in Python.
  • Stores multiple values in one variable
  • Supports indexing (0, 1, 2...)
  • Can be modified after creation
fruits = ["apple", "banana", "mango"]

print(fruits[0])
fruits.append("orange")

print(fruits)
