Learn how to learn with Code Academy.

Use this short orientation to understand the Courses page, choose the right course dashboard, open lessons, and return to the dashboard to continue learning. You can read this guide or listen to it using the voice controls below.

How the learning flow works

01

Find a course

On the Courses page, browse the course cards or use the search field to find HTML, CSS, JavaScript, Python, React, other programming tracks, Cybersecurity, or Ethical Hacking.

02

Select Start Course

The Start Course button should open that course’s own dashboard. Check the dashboard heading to confirm that you opened the course you selected.

03

Choose a lesson

Inside the course dashboard, select a lesson and use its lesson controls to begin studying. Read the explanations and follow any examples, quizzes, or coding activities provided.

04

Return and continue

When you finish a lesson, return to the course dashboard to choose the next lesson. Use the dashboard’s course-navigation control to leave the course and return to the Courses page.

05

Track your learning

Where available, use the progress, XP, completed-lesson, or streak information shown by the app to follow your learning. These values may depend on your signed-in account and saved progress.

06

Practise responsibly

Cybersecurity and Ethical Hacking teach defensive security and authorized testing. Only test systems, networks, or accounts that you own or have clear permission to assess.

Helpful tip: If a course opens a blank page or a different course, return to the Courses page and report the course name. Each Start Course button is intended to lead to its matching course dashboard.
