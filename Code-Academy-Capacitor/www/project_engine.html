✅ Todo App Beginner
Project Goal: Build a task management app where users can add, delete, and mark tasks as complete. Learn state management and event handling.
You will learn
• useState for task list management
• Form handling and input validation
• Array methods: map, filter for CRUD operations
• Conditional rendering for completed tasks
This project teaches core React concepts through a real-world app.

Features to build:
• Add new tasks with input field
• Mark tasks complete/incomplete with checkbox
• Delete tasks with button
• Show count of remaining tasks
• Filter: All, Active, Completed

Why this project: Every React developer builds a Todo app first. It covers 80% of basic React patterns you'll use daily.
Preview: Input field + Task list + Checkboxes + Delete buttons
