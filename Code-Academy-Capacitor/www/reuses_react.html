🔘 Button Component
What is it?
A Button Component is a reusable React component that accepts props. Props make it dynamic - you pass different text, color, and click function. Instead of writing button code 50 times, you write once and reuse everywhere.
Button.jsx - Complete Code
import React from 'react'; function Button({ label, color, onClick }) { return ( <button onClick={onClick} style={{ backgroundColor: color, padding: '12px 24px', borderRadius: '8px', border: 'none', color: 'white', cursor: 'pointer' }} > {label} </button> ); } export default Button; // USAGE IN APP.JSX function App() { return ( <div> <Button label="Submit" color="#10b981" onClick={() => alert('Submitted!')} /> <Button label="Delete" color="#ef4444" onClick={() => alert('Deleted!')} /> </div> ); }
🃏 Card Component
What is it?
A Card Component is a container that accepts title, description, and image as props. Uses children prop to accept any content inside. You build card structure once, then reuse for products, users, posts, etc with different data.

🧭 Navbar Component
What is it?
A Navbar Component accepts logo text and menu items array as props. Uses map() to render menu items dynamically. Change menu by just passing different array - no need to edit component code. True reusability.

Navbar.jsx - Complete Code
import React from 'react'; function Navbar({ logo, menuItems }) { return ( <nav style={{ display: 'flex', justifyContent: 'space-between', alignItems: 'center', padding: '16px 40px', backgroundColor: '#0b1220', borderBottom: '1px solid rgba(255,255,255,0.1)' }}> <h1 style={{color: '#8b5cf6'}}>{logo}</h1> <div style={{display: 'flex', gap: '24px'}}> {menuItems.map((item, index) => ( <a key={index} href={item.link} style={{color: '#cbd5e1', textDecoration: 'none'}} > {item.label} </a> ))} </div> </nav> ); } export default Navbar; // USAGE const menu = [ { label: 'Home', link: '/' }, { label: 'Courses', link: '/courses' }, { label: 'About', link: '/about' } ]; <Navbar logo="CodeAcademy" menuItems={menu} />
