Frequently asked questions

Helpful to know before you begin.

For detailed steps, examples, and feature boundaries, use the full documentation page.

Do I need to create an account to read Code Academy?

No. The public landing page, About page, documentation, Privacy Policy, and Terms of Use are available without authentication. Sign-in is used by selected features that need an account, cloud saving, or personal progress.

Can I learn and code on my phone?

The public pages and many learning tools are designed to fit mobile screens. Editors can be more demanding than lesson pages, and the available compiler or preview depends on the selected language, browser, and internet connection.

Does every language run directly inside the browser?

No. Some experiences use a browser preview or browser-based runtime; certain compiled languages use an external compiler service. Read the editor notice before running code, and never submit passwords, API keys, or private information in code.

Will Live Map use my location automatically?

The map can request location after you activate a location feature and grant your browser permission. Sharing a location is a separate action. You can decline permission, but location-dependent functions will not work.

Are Code Academy certificates accredited qualifications?

Certificates reflect records maintained by the app and are not automatically a government licence, university degree, industry accreditation, or guarantee of employment. Use the verification page to check a credential against the configured registry.

Is the cybersecurity or ethical-hacking content for attacking systems?

No. It is for learning defensive concepts and authorised testing. Test only your own systems or targets covered by clear permission. Never use lessons to access other people's accounts or systems without authorisation.

Where should I report a broken link or confusing lesson?

Use the Support Center or the relevant community route. Include the page name, what you expected to happen, what actually happened, and a screenshot only if it does not expose passwords, private details, or access tokens.
