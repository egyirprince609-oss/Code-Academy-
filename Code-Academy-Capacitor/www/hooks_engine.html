🪝 useState
State Management Hook
Definition: useState is a React Hook that lets you add state to functional components. It returns a stateful value and a function to update it.
useState allows components to "remember" information between renders. Without it, components would reset every time they re-render.

Key Points:
• Returns array: [currentValue, setValueFunction]
• Initial value only used on first render
• Calling setValue triggers re-render
• State updates are asynchronous
• Can use multiple useState in one component

⚡ useEffect
Side Effects Hook
Definition: useEffect lets you perform side effects in functional components. It runs after every render by default.
Side effects are operations that affect something outside the component. Like API calls, subscriptions, or manually changing DOM.

Key Points:
• Runs after render is committed to screen
• Empty [] = run only once on mount
• Return function = cleanup on unmount
• Dependencies array controls when it runs
• Can have multiple useEffect in one component

🌐 useContext
Context Hook
Definition: useContext lets you read and subscribe to context from React components without prop drilling.
Prop drilling is passing props through many levels. useContext solves this by creating a "global" data store for component tree.

Key Points:
• Must be used inside Provider
• Updates trigger re-render of all consumers
• Best for theme, user auth, language
• Eliminates need to pass props manually
