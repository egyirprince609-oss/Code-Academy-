# Code Academy Browser — Capacitor Android wrapper

This folder defines a separate Capacitor Android application (`com.codeacademy.browser`) and copies the files from its parent `browser/` folder into `www/` before a native build. The initial `android/` platform is generated by Capacitor on the builder's machine; it is not pre-generated in this source archive.

## Build on a computer with Node.js and Android Studio

1. Open a terminal in `browser/capacitor/`.
2. Run `npm install`.
3. Run `npm run add-android` once to create the Android platform, or `npm run sync` if it already exists.
4. Run `npm run android` to open Android Studio.
5. In Android Studio, allow Gradle/SDK setup, test on a device, then choose **Build > Generate Signed Bundle / APK** and create a new signing key stored securely outside the repository.

The standalone APK cannot be produced by this web source folder alone: building requires Android SDK/Gradle and a signing process. Never commit the keystore or passwords.

## Important browser capability notes

The web PWA uses a sandboxed iframe for site preview; many sites refuse iframe embedding. A real all-sites browser needs a native top-level WebView/navigation host, Android download and permission handlers, and carefully reviewed navigation policies. The PWA cannot silently register itself as Android's default browser. Add Android `VIEW` intent filters and request the browser role in native Android code, and let the user choose the default in system settings. Do not add broad file access or disable certificate validation to make sites load.
