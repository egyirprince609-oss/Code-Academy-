# Code Academy — 200 Lesson JSON Bank

This package contains 200 lesson files: 20 courses × 10 lessons. Filenames follow the loader pattern in `lesson.html`, such as `html_lesson_1.json` and `python_lesson_10.json`. JSON keys preserve the existing lesson-engine structure (`course`, `lessonNumber`, `lessonId`, lesson metadata, and ordered `blocks`). Supported block types used here are `heading`, `sentence`, `content`, `code`, and `quiz`.

Each lesson is organized into three labeled teaching pages. Newly authored lessons include four code examples, five four-option multiple-choice application questions, a correct option index, and explanations that justify the answer. The existing readable HTML, CSS, JavaScript, and React lessons are preserved and only normalized for route metadata, page anchors, and missing sample/feedback requirements. `html_lesson_4.json` is rebuilt because the original ZIP contained an empty/invalid file.

## Installation

Copy the 200 JSON files into the same location used by the current `lesson.html` fetch path. Do not rename files: the course identifier and lesson number must match the route generated by the app. After uploading, open representative lessons on the deployed site and check browser/network errors, code-card display, question feedback, and mobile layout.

## Notes

Examples are teaching snippets, not a replacement for a project compiler. Some examples are intended to be placed inside the surrounding function or class required by the language, as explained in the lesson. SQL is dialect-sensitive; statements use common SQL patterns and parameter placeholders where user input is involved.
