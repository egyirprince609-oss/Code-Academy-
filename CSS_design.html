10 Must-Know Responsive Code Patterns

1. Mobile First Media Query

Basic Structure
/* Mobile styles first */ .container { width: 100%; padding: 16px; } /* Tablet and up */ @media (min-width: 768px) { .container { max-width: 720px; margin: 0 auto; } }

2. Fluid Typography

Clamp Function
h1 { font-size: clamp(2rem, 5vw, 4rem); /* Min, preferred, max */ } p { font-size: clamp(1rem, 2.5vw, 1.25rem); }

3. Flexible Grid

Auto-fit Grid
.grid { display: grid; grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)); gap: 20px; }

4. Responsive Images

Image Scaling
img { max-width: 100%; height: auto; object-fit: cover; }

5. Container Queries

Modern Approach
.card-container { container-type: inline-size; } @container (min-width: 400px) { .card { display: flex; } }

6. Viewport Units

VH/VW Units
.hero { height: 100vh; width: 100vw; } .section { padding: 5vw 10vw; }

7. Hide/Show Elements

Display Toggle
.desktop-nav { display: block; } @media (max-width: 768px) { .desktop-nav { display: none; } .mobile-menu { display: block; } }

8. Flexbox Wrap

Flexible Layout
.flex-container { display: flex; flex-wrap: wrap; gap: 16px; } .flex-item { flex: 1 1 300px; }

9. Aspect Ratio

Keep Proportions
.video-wrapper { aspect-ratio: 16 / 9; width: 100%; } .square { aspect-ratio: 1 / 1; }

10. Touch Targets

Mobile UX
button, a { min-height: 44px; min-width: 44px; padding: 12px 24px; } /* Apple & Google recommendation */
