Frequently Asked Questions
Q1: Why is my lesson not loading?
Try refreshing the page or checking your internet connection. If problem persists, clear browser cache and try again.
Q2: How do I earn XP?
XP is earned by completing lessons, quizzes, challenges, and Logic Arena games. Each completed activity adds XP to your account automatically.
Q3: How do I join WhatsApp group?
Click the "Join WhatsApp Group" button above. You'll be redirected to our official community group where students help each other.
Q4: I forgot my password, what should I do?
Use the "Forgot Password" link on login page. You'll receive a reset link via email. If you don't see it, check spam folder.
Q5: Can I use Code Academy offline?
Currently Code Academy requires internet connection. Offline mode is coming in future updates. Stay tuned!
