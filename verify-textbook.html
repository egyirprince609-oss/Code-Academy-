What you should check

1. Matching title

The registered course and title should match the printed book.

2. Matching code

The ID and verification code must both match; an ID alone is insufficient.

3. Edition details

Compare edition, publication year, author, and publisher details.

4. Unrecognized record

A copied logo, QR image, or barcode alone is not proof that a book is official.
