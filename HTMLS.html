💻 Complete Website Skeleton Template

Copy this for EVERY website you build. This is the foundation!

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Website</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    
    <!-- HEADER: Top of website -->
    <header>
        <h1>My Website Logo</h1>
    </header>
    
    <!-- NAVIGATION: Menu -->
    <nav>
        <a href="index.html">Home</a>
        <a href="about.html">About</a>
        <a href="contact.html">Contact</a>
    </nav>
    
    <!-- MAIN: All content goes here -->
    <main>
        
        <!-- SECTION 1: Hero/Banner -->
        <section>
            <h2>Welcome to My Site</h2>
            <p>This is the main banner area</p>
        </section>
        
        <!-- SECTION 2: About -->
        <section>
            <h2>About Us</h2>
            <p>Information about your website</p>
        </section>
        
        <!-- SECTION 3: Services/Products -->
        <section>
            <h2>Our Services</h2>
            <p>What you offer</p>
        </section>
        
    </main>
    
    <!-- FOOTER: Bottom of website -->
    <footer>
        <p>Copyright © 2026 My Website</p>
        <p>All rights reserved</p>
    </footer>
    
</body>
</html>

🔍 Breakdown - What Each Part Does

1. <!DOCTYPE html>
Tells browser: "This is HTML5". Always first line.

2. <html>
Root container. Everything goes inside this.

3. <head>
Invisible section. Contains title, meta tags, CSS links. Not shown on page.

4. <body>
Visible section. Everything users see goes here.

5. <header>
Top section. Logo, website name, search bar.

6. <nav>
Navigation menu. Links to other pages.

7. <main>
Main content area. Only ONE main per page.

8. <section>
Content blocks. Split your page into sections.

9. <footer>
Bottom section. Copyright, contact info, links.

⚡ 5 Golden Rules

1. Always start with <!DOCTYPE html>

2. Only ONE <main> tag per page

3. <head> = invisible, <body> = visible

4. Use semantic tags: header, nav, main, section, footer

5. Close every tag you open!
