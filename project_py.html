🧮 Project 1: Python Calculator (Deep Explanation)

🔹 Line 1

num1 = float(input("Enter first number: "))

👉 Meaning: This line asks the user to type the first number.

👉 Explanation: - input() collects text from the user. - float() converts that text into a decimal number. - num1 stores the final numeric value.

👉 Why used: We need numbers for calculations, not text.

🔹 Line 2

op = input("Enter operator (+ - * /): ")

👉 Meaning: This line asks the user to choose an operation.

👉 Explanation: - input() stores what the user types. - op holds symbols like +, -, *, /

👉 Purpose: To decide what mathematical operation to perform.

🔹 Line 3

num2 = float(input("Enter second number: "))

👉 Meaning: This collects second number.

👉 Explanation: - same as num1 - ensures second value is numeric

👉 Purpose: We need two numbers for calculation.

🔹 Condition Block

if op == "+":
    print("Result:", num1 + num2)

👉 Meaning: If user selects +, add numbers.

👉 Explanation: - if checks condition - == means “is equal to” - print shows result

👉 Purpose: Controls program decision flow.

🔹 Full Code

num1 = float(input("Enter first number: "))
op = input("Enter operator (+ - * /): ")
num2 = float(input("Enter second number: "))

if op == "+":
    print("Result:", num1 + num2)
elif op == "-":
    print("Result:", num1 - num2)
elif op == "*":
    print("Result:", num1 * num2)
elif op == "/":
    print("Result:", num1 / num2)
else:
    print("Invalid operator")

🎮 Project 2: Guess Game (Deep Explanation)

🔹 Line 1

import random

👉 Meaning: Loads Python’s random module.

👉 Explanation: - import brings external features into program - random allows number generation

👉 Purpose: To generate unpredictable numbers.

🔹 Line 2

secret = random.randint(1, 10)

👉 Meaning: Computer picks a random number.

👉 Explanation: - randint(1,10) selects number between 1 and 10 - stored in secret variable

👉 Purpose: This is the hidden answer user must guess.

🔹 Loop

while guess != secret:

👉 Meaning: Repeat until correct guess.

👉 Explanation: - while means loop continues - != means “not equal to”

👉 Purpose: Keeps game running until correct answer. 

import random

secret = random.randint(1, 10)
guess = 0

while guess != secret:
    guess = int(input("Guess number (1-10): "))

    if guess < secret:
        print("Too low!")
    elif guess > secret:
        print("Too high!")
    else:
        print("Correct!")
