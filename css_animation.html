CSS Animation Lesson

📖 What is CSS Animation?

CSS Animations allow elements to move, rotate, fade, grow, shrink and perform visual effects. Animations make websites more interactive and professional. Examples include:

  • Loading Spinners
  • Animated Buttons
  • Menus
  • Game Effects
  • Notification Popups

📝 Animation Syntax

selector{ animation:name duration; }

animation = CSS property used to animate elements.

name = animation name.

duration = how long animation runs.

💻 Example Code

.box{ width:100px; height:100px; background:skyblue; animation:bounce 2s infinite; } @keyframes bounce{ 0%{ transform:translateY(0); } 50%{ transform:translateY(-50px); } 100%{ transform:translateY(0); } }

🔍 Line-by-Line Explanation

.box Creates a CSS class called box.

width:100px; Sets the width of the box to 100 pixels.

height:100px; Sets the height of the box to 100 pixels.

background:skyblue; Changes the background color to sky blue.

animation:bounce 2s infinite; Starts an animation named bounce. 2s means the animation lasts 2 seconds. infinite means it repeats forever.

@keyframes bounce Creates an animation called bounce.

0% Animation starting position.

transform:translateY(0); Keeps the box in its original position.

50% Middle point of animation.

transform:translateY(-50px); Moves the box 50 pixels upward.

100% Animation ending point.

transform:translateY(0); Returns the box back to its original position.

🎬 Live Output

The box moves up and down continuously.
