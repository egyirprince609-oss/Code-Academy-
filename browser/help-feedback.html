CODE ACADEMY BROWSER

Help & feedback

Common questions, limits and diagnostics for the browser workspace.

Why does a website say it cannot be shown?

Some sites block being displayed inside another webpage using security headers. The PWA cannot override those restrictions. The Android native WebView wrapper needs to open that destination as a top-level WebView page.

Does private mode make me anonymous?

No. It can limit what this app stores locally or syncs, but it does not hide traffic from websites, your mobile provider, network administrator, or internet provider.

Why didn't my tabs sync?

Local tabs still work when Firebase or Firestore rules are unavailable. For cloud sync, allow the signed-in user to access the browserProfiles collection and its own subcollections. Full errors appear in the browser status area.

Can the webpage set Android as the default browser?

No webpage can silently change Android’s default app. The native Android project must declare eligible VIEW intent filters and request that the user select it through system settings. This requires native Android integration.

What is encrypted?

Network requests should use HTTPS and Firebase Authentication protects account credentials. This browser interface does not implement end-to-end encryption for local history or bookmarks; use your device’s lock and do not store sensitive information in browser history.
