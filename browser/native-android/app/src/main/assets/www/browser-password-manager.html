Manage saved sign-in details

Code Academy Browser never reads passwords saved in Android, Google Password Manager, or another browser. The buttons below open official account/help destinations where supported.

Some controls open a separate system or Google page because browser pages cannot inspect protected password vaults.

Browser autofill preference

Use the saved preferences to decide whether Code Academy Browser should display autofill-related guidance. Actual autofill is controlled by the browser engine and Android.

Security reminders

Use a strong device screen lock, never share one-time codes, and avoid saving passwords on shared devices. Reset forgotten passwords only through the original account provider.
